# Excel Sales Analysis Dashboard

Portfolio project developed in Microsoft Excel using a small synthetic sales dataset with 60 records.

## What I built

- Enriched the sales data with product, category, and price information using `XLOOKUP`.
- Calculated gross revenue, discount amount, and net revenue.
- Classified sales with `IF`.
- Created summaries with `SUMIFS` and `COUNTIFS`.
- Created a month field with `DATE`, `YEAR`, and `MONTH` to keep the analysis in chronological order.
- Built PivotTables to analyze revenue by region, salesperson, category, and month.
- Created four charts and assembled a simple dashboard to present the results.
